## 9. Method and limits

- Imports: static `import ... from`, side-effect `import '...'`, `export ... from` and literal `import('...')`, parsed from comment-stripped source (string, template and regex-literal aware); named, default and namespace imports (namespace: the NS.Name uses) give the requested names.
- A TV import is resolved at TV's own path (identity map after W0-02) against the VV git index; 'missing' = no file at that path; 'present_names_missing' = the file exists but does not export every requested name (export * followed).
- Seams are never ports: 80__CloudflareIntegration/LocalProjectMirror__ (and anything outside the TV app root) -> transport seam (DIV-4) resolved by the W0-12 facade; TV 41__System__SectionCutEngine -> SectionAdapter (DIV-2); TV 40 ProfileLines -> dropped (DIV-1).
- Take modes per package come from the package text (goal, vv_adaptations, tv_sources annotations); every non-new target was classified by hand (OVERRIDES table in the script). 'whole' and 'convergence' are checked strictly (defects). For 'hunks' only the TV imports the package wires are checked (it lands or edits the target, or its text names the module or an imported name); those failures are 'hunk_defects'; the rest stay VV's own imports.
- A name VV lacks counts as delivered by an earlier hunk package when that package's text names it (e.g. W0-11 adds the ProjectLoader helpers); a whole take whose package declares 'facade-only imports' (W1-34) takes LE names through the lazy-loader facade (R3 C.4 S5).
- Order check: a prerequisite landed by package L is fine for consumer P when L == P, L is in an earlier wave (R11 barrier) or L is a transitive depends_on ancestor of P in the same wave; a held lander never satisfies a non-held consumer.
- Levels: Tarjan SCCs over the 'missing or needs-upgrade' edges between TV modules reachable from the whole-take set; level 0 = no blockers; a module's level = 1 + the highest level of its blockers (leaves first, hubs last).
- Take modes: each package's TV sources were read from its goal, adaptations and tv_sources annotations; the hand classification of every non-new target is the `OVERRIDES` table in the script (with the quoted basis), so the planner can audit or change any call.
- Not checked: names reached only through `import * as NS` without `NS.Name` uses, dynamic `import()` with computed specifiers, and JSON or CSS loaded through `fetch` (resource references are listed separately). Runtime behaviour is out of scope.
