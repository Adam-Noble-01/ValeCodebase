# K1 - Decision Register: ValeVision 3D Drawing System alignment with TrueVision 3D

Synthesis stage, agent K1, 01-Oct-2026. Source of truth for the planner: `parity/data/decision_register.json` (the canonical decisions) and `parity/data/decision_raw_map.json` (every raw id mapped). Built and validated by `parity/report/tools/k1_build_register.py` from `parity/report/tools/k1_register_content.py`.

**Inputs merged:** 216 raw decisions from 18 slices (`decisions.json`) and 147 decision-type findings (category `decision` or action `needs_decision`), 363 ids in all, merged into **44 canonical decisions**; 1 id dropped with a reason. Every id maps to exactly one DR (proof at the end).

**How to read it**

- DR ids are ordered by urgency: `before Wave 0` (DR-01 to DR-07), then `before the wave that needs it` (scope, then seams, then versioning, ledger and TrueVision permission, then UI details), then `can wait`.
- Wave 0 = the serialised foundation wave run before any feature port: the folder renumber package (WP-S01-01R, carrying the DR-03 and DR-04 moves), the ledger restructure (WP-S11-01), the port-note verifier (WP-S11-03), the port-order map from TV's import graph (WP-S11-08), and the sync-pipeline fix prepared for Adam (WP-S12-01).
- default_if_unanswered follows the recommendation, except where acting would (1) edit TrueVision, (2) change shared Vale infrastructure (the Whitecardopedia service worker, registrar or sync pipeline), (3) deploy anything (the VV worker, GitHub Pages), (4) delete, migrate or re-bake live data, or (5) put NA content, or a gesture change Adam has not confirmed, in front of Vale users. In those cases the default is the safe status quo until Adam answers, and the gated work is prepared but not applied.
- Paths: TV/ and VV/ are the app roots; TVM/ and VVM/ are their `02__Src__AppModules`; LE = `51__System__LayoutEditor`; WCP = `D:\10_CoreLib__ValeCodebase\WebApps\Whitecardopedia`; NAAPPS = `D:\11_RefLib__StudioRepository__RemoteSystem\NaWeb\na-apps`. Every path:line in 'What the code shows' was opened on 01-Oct-2026 unless it is attributed to a slice.
