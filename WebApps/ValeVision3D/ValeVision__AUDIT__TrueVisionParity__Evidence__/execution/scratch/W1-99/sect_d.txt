### 1.3 IsSitePlanSheet: TV's rule on both sides of the load (R3 wording "after load answer false" not followed literally)

R3 C.2 (a3) says "after load answer false while the editor lacks Na__LeModel__IsSitePlanSheet". The package

"False in VV" (R4, S10) still holds in practice: no VV record carries Sheet__DrawingType (DR-08 (B), dormant).

### 1.4 Ready: settles with the first load, never causes one

S10's verifier lists Ready as "not needed" by the strip (W1-34 drops TV's `Ready().then(Render)`); K3 lists it, so it
is provided with a definite meaning: forwards to `editor.mode.Na__LeMode__Ready()` once loaded; `false` once the
editor's config is known to have it off; otherwise a pending promise settled by the first load (true started,
false off or failed). The same answer whether asked before or after the load (test: before -> pending -> true after
the load; asked after -> true; config off -> false both sides; failed load -> false). A caller that needs the
editor calls Na__LeLoad__Require.
