## Follow-ups for Adam

1. **"T01" in new Vale statement file names (config, not this package).** Data__Index names a new statement file from `setup.filePattern`, with TV's fallback `{code}_T{tranche}_S{number}__...`. VV's `Na__LayoutEditor__AppConfig__.json` (`LayoutEditor__Statement__FilePattern` / `__DefaultTranche`, landed by an earlier package) carries TV's values, so a new Vale statement would be named `3047_T01_S01__...`. The "T01" is NA's job-phase form, which Vale ids should not carry (K2 V2 / execution policy 9).
   - When you switch the Statement Writer on, decide a Vale pattern; for example, drop `_T{tranche}`.
   - It is a config value change only, and no code changes.
