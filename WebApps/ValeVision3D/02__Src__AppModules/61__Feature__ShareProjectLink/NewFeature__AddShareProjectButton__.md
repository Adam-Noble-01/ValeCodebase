# New Feature: Add Share Project Button
- Add a new button to the end of the toolbar (At the bottom)
- When the button is clicked, it will prompt the user to enter the recipients name.
  - If Names seperated by commas, this will address the email generated to each recipient.
- It then generates and downloads a Email .html file that contains the project link and the recipient/s name.
- Use the template provided in the "60__DistributionEmails" folder.
