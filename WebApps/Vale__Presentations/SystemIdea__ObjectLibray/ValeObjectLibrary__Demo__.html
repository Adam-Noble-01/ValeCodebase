Scheme Level Definition

The Scheme represents the top level configured project or design option. A Scheme contains the selected Families, Assemblies, Components and Products required to define a complete Vale Garden Houses project. Schemes should be version controlled so multiple design options and revisions can be maintained.

Assemblies And Construction Objects

Assemblies are objects constructed from multiple Components or Products. Assemblies can also contain other Assemblies where additional hierarchy is required.

Common examples include Door Assemblies, Window Assemblies, Pilaster Assemblies, Roof Rafter Assemblies, Ridge Assemblies, Hip Assemblies, ETR Vent Assemblies and Framework Assemblies.

Configurable Fabricated Components

A Component is a fabricated or configurable element rather than a fixed purchased object. Components will commonly vary in length, width, depth or other parameters depending on the configuration of the Scheme.

Examples include Cornice, Entablature, Glazing Bar, Door Stile, Door Rail, Fielded Panel, Cill, Fascia, Frieze, Mullion, Pilaster Base, Pilaster Shaft, Pilaster Capital and Glazing Panel. Components may reference one or more Resources such as profiles, materials, finishes or specifications.

Discrete Purchased Products

A Product is a discrete and identifiable item which generally exists as a known object, casting, SKU or purchased product. Examples include Door Handles, Hinges, Finials, Cresting Sections, Locks, Espagnolettes, Vents, Brackets and Gutter Outlets.

Typical Product data includes Product Code, Supplier or Manufacturer, Fixed or Selectable Sizes, Material, Finish, Cost, Weight, CAD or 3D Asset and Availability or Status. Products can be referenced by Assemblies without needing to duplicate the underlying Product record.

Database Reusable Resources

Resources represent the lowest level reusable definitions within the database. Resources are generally not complete physical objects by themselves. Instead, they define the profiles, materials, specifications and other data used by Components, Products and Assemblies. A single Resource should be reusable across multiple Components and Assemblies.

Database Concept And Structure

The Object Library contains the reusable definitions from which Vale projects are configured. Resources build into Components and Products, which build into Assemblies, which combine into Families, culminating in a Scheme.

Configuration Engine Rules

The engine controls how objects can be selected, sized, combined and configured using Rules, Parameters and Constraints. Examples include Dimensional Rules, Compatibility Rules, Quantity Rules, Product Selection Rules, Minimum and Maximum Sizes, Spacing Rules, Manufacturing Constraints and Design Constraints.

Configured Scheme Implementation

A Scheme contains configured instances of objects from the Object Library. The library definition remains reusable while each Scheme stores the actual configured dimensions, quantities and selections.

Associated Asset Library

Associated data can be linked to any relevant database object. Examples include Manufacturing Data, Cost Data, CAD, SketchUp Models, 3D Models, Photographs, PDF Drawings, Data Sheets, Technical Specifications, Supplier Information, Installation Information and Historical or Revision Data.
