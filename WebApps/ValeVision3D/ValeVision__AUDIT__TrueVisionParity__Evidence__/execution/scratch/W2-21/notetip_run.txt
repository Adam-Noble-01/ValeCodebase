
TrueVision3D - a bubble names its note, and finds it

  The note resolver (the shipped LeaderGeometry and SpecLinks)
  PASS  the geometry: the circle, the tail and the tip are told apart
  PASS  with nothing registered a bubble stands for no note
  PASS  SpecLinks registers NoteOf as the note resolver
  PASS  a linked bubble: its note, its code, its title, linked
  PASS  locate() asks for the note to be shown in the Specification tab
  PASS  an unlinked bubble reading a note's code: that note, not linked
  PASS  a broken bubble (its note deleted) stands for none
  PASS  a bubble reading a code no note has stands for none
  PASS  a note leader, not a bubble, stands for none
  PASS  before the specification has loaded, none
  PASS  a resolver that throws reads as no note

  The tooltip (the shipped NoteTooltip, a clock the test turns)
  PASS  resting on a bubble shows nothing at once
  PASS  ...nor a moment short of NoteTooltipMs
  PASS  ...then the code in bold and the note's title, beside the pointer
  PASS  moving on the same bubble, the label follows the pointer
  PASS  off the bubble it is let go (the hover pass has already hidden it)
  PASS  straight on to the next bubble names it at once, "Untitled note" for a note with no title
  PASS  the tail is not the bubble: nothing
  PASS  a bubble inside a group is found through it
  PASS  a bubble on a LOCKED layer, which clicks pass over, still names its note
  PASS  one on a REFERENCE layer does not: nothing on it answers the pointer
  PASS  a tool picked up while it waited: nothing is shown
  PASS  a press (or a key, a wheel turn, the pointer leaving) takes it down
  PASS  ...and taking down nothing hides nothing (a broken bubble's message is left alone)
  PASS  NoteTooltip false in the config: never
  PASS  NoteTooltipMs 0: at once
  PASS  a note renamed while its label is up is named afresh
  PASS (to THE MENU)
