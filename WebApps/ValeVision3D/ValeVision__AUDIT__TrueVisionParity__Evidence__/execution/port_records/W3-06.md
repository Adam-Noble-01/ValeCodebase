## Procedure (scripts in execution/scratch/W3-06/)

1. `tv/` holds the four TV files and TrueVision__DEVLOG__.md at b2aa9151.
2. `port_w3_06.py --stage` builds the staged files from TV's bytes. It asserts each of the 7 replacements happens exactly once and that no TRUEVISION3D or [TrueVision3D token is left.
3. `node --check` runs on the staged files.
4. `port_w3_06.py --apply` backs up the live bytes to backup/, then writes each file whole. It records each file's SHA-256 in state.json.
5. The test, the gates, the diff check and the suite run on the result.
6. `port_w3_06.py --restore` puts the backups back. It refuses if a file has changed since W3-06 wrote it.
