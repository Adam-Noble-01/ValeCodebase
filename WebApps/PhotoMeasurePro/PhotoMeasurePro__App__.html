    Visual Settings

    Setup

    Z-up coordinates. Align Red (X, facade-horizontal), Green (Y, side-horizontal), and Blue (Z, vertical) lines to parallel features. Pair labels auto-pick Top/Bottom for X/Y and Left/Right for Z.

    Constraint

    Pick a plane, set its real-world length, then draw one known-length line on the image for that plane. Repeat per plane, or set an Anchor Corner to propagate one plane's scale to the others.

    • Facade: not set
    • Side: not set
    • Ground: not set

    Anchor Corner

    Click the shared corner where facade, side, and ground meet. Any one constraint then scales all planes.

    Anchor: not set

    Measurement

    Angle: click vertex, then arm 1, then arm 2. Press Esc to cancel.

    Warning: the selected plane has no scale. Set a constraint (or anchor + any constraint) to get mm.

    Ortho View

    Rectified elevation for the selected plane. Pan with middle/right drag. Zoom with the wheel. Use Crop to pick an export region.

    3D Measure

    Build an analytical 3D scene from calibrated planes, then optionally enhance with depth + segmentation.
