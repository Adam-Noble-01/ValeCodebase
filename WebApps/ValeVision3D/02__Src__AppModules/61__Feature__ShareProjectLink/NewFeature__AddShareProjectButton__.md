# New Feature: Add Share Project Button
- Add a new button to the end of the toolbar (At the bottom)
- When the button is clicked, it will prompt the user to enter the recipients name.
  - If Names seperated by commas, this will address the email generated to each recipient.
- It then generates and downloads a Email .html file that contains the project link and the recipient/s name.
- Use the template provided in the "60__DistributionEmails" folder.
    - `Distro__InviteEmailEmbedCard__ValeVision3d.html`
- Populate the email with the project link in form of a clickable button (Template uses a placeholder so switch for the actual project link
- Populate the email with the recipient/s name (Template uses a placeholder so switch for the actual recipient/s name)
- Populate the email with a unique project ID (Template uses a placeholder so switch for the actual project ID)
- Add a "Special Notes" section to the email with a message to the recipient/s. if nothing is entered, this section will not be displayed. 
  - If text is entered, this section will be displayed on a card (Blockquote style with the Vale Blue Tab colour).
