## IMPLEMENTATION PATTERN

All asset URLs follow this pattern:

```javascript
// CORRECT - Absolute URL
src="https://adam-noble-01.github.io/ValeCodebase/WebApps/assets__CommonApplicationAssets/[path]"

// INCORRECT - Relative URL (old pattern)
src="../assets__CommonApplicationAssets/[path]"
```

This ensures assets load correctly on GitHub Pages deployment regardless of the page depth or routing structure.
